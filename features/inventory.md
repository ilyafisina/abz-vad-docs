# Карточка позиции

В карточке отображается подробная информация о материале.

![Карточка позиции](card.png)

| Параметр | Описание |
| :--- | :--- |
| Код АБПХ | Уникальный идентификатор позиции |
| Текущий остаток | Фактическое количество на складе |
| Зарезервировано | Количество, зарезервированное под заказы |
| Доступно | Свободный остаток (Остаток - Резерв) |

Для перемещения материалов используйте экран **Приёмка**.
